## 3. Deviations from the brief, and why

- **Two fix commits beyond the stage cadence**, both tiny and single-file: `aac4779` (stage 1's queue float missed the case where coach cards already sat in the chunk — caught by AG-007's own stage-3 test) and `90e7339` (pre-recorded `PlaybackReview` full-suite flake; 20 lines of headroom in the save wait).
- **Top-up same-day type exclusion.** The brief said ≤3 batches/day; the code additionally excludes a type already topped up today, because a second same-day batch would reuse `topup-<date>-<type>-<i>` ids and overwrite the first. Documented in `topUp.ts`.
- **`week_plan` schema ALTER missed at stage 5, closed in stage 6.** Both-way mappers existed at `d16b2fc`, but the schema half of §0.6 was not in that commit; `speak/supabase/schema.sql` now carries the ALTER and the AG-009 SQL block includes it.
- **App.tsx carried a BOM** (from before this work); stage 5 stripped it to honour UTF-8/no-BOM.
- **`weekPlanFromRemote` treats `{}` as a legitimate presence** for the weight maps (an empty object is a real value, not "missing"); malformed plans are dropped whole. Tested in `supabase.test.ts`.
- **Test-only accommodations:** `ai.test.ts` uses a unique `x-forwarded-for` per test (the function's 30 req/min limiter is in-memory per IP); `aiFunction.test.ts` fixture updated to the 5-task list; deliberate invalid-value casts (`'x' as unknown as number`) in `plan.test.ts` clamp tests. No production types loosened.
