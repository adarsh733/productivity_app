## Fixed names
Copied word for word into every pass. All paths are under `speak/` unless shown otherwise.

**Branch:** stay on `v4-usable`. Never touch `master`, never push, never deploy.

**Contract (written once, by p2, in `src/types/contract.ts`; additive only — nothing existing changes shape):**
- `export type Track = 'smalltalk' | 'stories' | 'clearly' | 'words';` — display names 💬 Small talk · 📖 Stories · 🎯 Speak clearly · 🔤 Words
- `export type TrackLevel = 1 | 2 | 3 | 4 | 5;`
- `export type CardKind = 'learn' | 'use' | 'fix' | 'try' | 'ask_them';`
- `CardType` gains `'teach'`; `export interface TeachCard extends CardBase` with `type: 'teach'; track; level; kind; category: string; title; rule; examples: { work: string; everyday: string }; insteadOf?; analogy; tryPrompt; register: 'casual' or 'office' or 'both'; answer?` (the revealed great answer on Try cards) `; source?; lesson?: { id: string; title: string; step: 1-5; order: number }; links?: string[]` (lesson ids a Fix card points to)
- `export interface SkillTag { track; level?; kind; work?; everyday?; analogy?; insteadOf?; answer? }` and optional `skill?: SkillTag` on `CardBase` (how reshaped old cards carry the new parts)
- `export type TeachDraft` = TeachCard minus CardBase fields and `lesson`, plus `type: 'teach'`
- `export type AskKind = 'word' | 'phrase_idiom' | 'mistake' | 'fix_sentence' | 'topic' | 'how_say' | 'difference' | 'other';`
- `AskRecord { id; createdAt; text; askKind; answer; cardIds: string[]; addedToFeed: boolean }` · `WeakSpot { id; wrong; right; source: 'ask' or 'chat'; createdAt; fixedAt? }` · `LessonProgress { lessonId; doneAt }` · `ChatSession { id; day; turns: ChatTurn[] }` · `ChatTurn { question; transcript; wpm?; loudness?: 'below' or 'normal' or 'above'; feedback?: CoachChatResult }` · `StoryBankEntry { id; day; text; createdAt }`
- `AnswerAskPayload { text; avoid?; levels? }` → `AnswerAskResult { askKind; answer; versions?: { crisp; confident; polite }; chunks?: string[]; weakSpot?: { wrong; right }; cards: TeachDraft[] }`
- `CoachChatPayload { question; transcript; track; wpm?; loudness?; voicedSec?; watch? }` → `CoachChatResult { good: string; fixes: { text: string; lesson?: string }[]; better: string; slip: { wrong; right } or null }`
- `AiTask` gains `'answer_ask'` and `'coach_chat'`. `TranscribeResult { text; words: { word; start; end }[]; durationSec }`

**Data:** Dexie `version(6)` in `src/db/db.ts` adds tables `lessonProgress` (key `lessonId`), `asks` (`id, createdAt`), `weakSpots` (`id, createdAt`), `chats` (`id, day`), `storyBank` (`id, day`). Phone-only (no Supabase columns) unless question 8 says otherwise.

**Shell:** `AppTab = 'feed' | 'ask' | 'me'`. Old Browse / Speak / You / voice lab / onboarding / Capture / coach box stay in the code and open from the ⚙︎ on Me through `src/components/me/OldToolsSheet.tsx`. XP and the Hindi share are off in the feed; Hindi cards stay in the database.

It is generated from `../docs/AI-RULEBOOK.md` by `node speak/scripts/build-rulebook.mjs`; `--check` exits 1 when the two differ.

**Models in `netlify/functions/ai.ts`:** Groq `openai/gpt-oss-120b`, Anthropic `claude-haiku-5-5`, Gemini per question 3. Provider order stays Gemini → Groq → Anthropic (locked); `coach_chat` sends `prefer: 'anthropic'` (frozen: Haiku coaches). Every AI card still goes through `verify_batch` on a DIFFERENT provider (`features/coach/pipeline.ts` `verifyDrafts`).

**Transcription:** `netlify/functions/transcribe.ts` → `/.netlify/functions/transcribe`, Groq `whisper-large-v3-turbo`, `verbose_json` with word timestamps.

**Lesson rotation:** `src/features/lessons/rotation.ts` `todaysTrack(day: DayKey): Track`, order smalltalk → stories → clearly → words, one lesson a day.

**Track for old cards:** `src/features/skills/trackOf.ts` `trackOf(card: Card): SkillTag` — the card's own `skill` if set, else by type: word/swap/idiom/feeling/action_verb → words · phrase → clearly · story_move → stories · situation → Try (track by its kind).
